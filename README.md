## Featured project: Function Explorer

**An interactive app that graphs any function you type and checks whether it is injective, surjective, bijective, and continuous.**

[![Function Explorer showing x squared failing the horizontal line test](https://raw.githubusercontent.com/kjlbivens/function-explorer/main/x2_all_reals.png)](https://kelseybivens.shinyapps.io/FunctionExplorer/)

Students often memorize these definitions without seeing why they work. Function Explorer lets you type a function, choose its domain and codomain, and see each property tested on the graph, with a plain-language explanation. For example, x² is not one-to-one on all real numbers, but it becomes bijective when you restrict the domain to x ≥ 0 and the codomain to y ≥ 0. I tested the app on 21 functions and compared its answers to formal proofs. They matched every time.

- **Try the live app:** [kelseybivens.shinyapps.io/FunctionExplorer](https://kelseybivens.shinyapps.io/FunctionExplorer/)
- **Full report:** [Checking Function Properties with Proofs and an App](https://github.com/kjlbivens/function-explorer/blob/main/REPORT.md)
- **Code:** [github.com/kjlbivens/function-explorer](https://github.com/kjlbivens/function-explorer)

## Earlier projects

### Gradient Descent Optimization

Models quadratic optimization problems in one and two variables, compares the numerical results of gradient descent with the exact solutions from calculus, and discusses how gradient descent is used in machine learning.

- **Report:** [Gradient Descent Optimization (PDF)](https://github.com/kjlbivens/MathModelingPortfolio/blob/main/Project%208-Part%20A.pdf)

### Fuel Consumption Regression

Predicts convoy fuel consumption with linear regression on a dataset of 150 trips, using vehicle weight, distance traveled, and average speed. Includes scatterplots, interpretation of each coefficient for logistics planning, and an interactive Shiny app.

- **Report:** [Fuel Consumption Regression (PDF)](https://github.com/kjlbivens/MathModelingPortfolio/blob/main/Project%208-Part%20B.pdf)
